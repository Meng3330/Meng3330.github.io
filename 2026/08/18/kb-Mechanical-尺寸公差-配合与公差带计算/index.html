尺寸公差、配合与公差带计算

2026-08-18 2026-08-18 1983 字数 ~7 分钟 机械原理
# 知识库 # 机械原理

尺寸公差用一个允许区间表达“零件不必完全相同，但仍能满足功能”。互换性的重点不是把公差压到最小，而是在满足装配、运动、强度和寿命的前提下，为制造保留合理的变动范围。

互换性的层次

  • 完全互换：零部件不经选择、修配或调整即可装配并满足规定功能，适合标准件和批量生产。
  • 不完全互换：通过分组选择、调整或修配实现最终装配要求，适合直接加工到完全互换精度不经济的场合。

不完全互换不是“可以不满足要求”，而是把一部分精度保证工作从单件制造转移到分组或装配阶段。选择哪种互换方式，应比较制造、检验、库存和装配的总成本。

尺寸、偏差与公差

  • 基本尺寸是设计给定的基准尺寸，是零线所代表的尺寸，不是“越接近越好”的唯一目标值。
  • 上、下偏差是极限尺寸与基本尺寸的代数差，可为正、负或零。
  • 公差是上偏差减下偏差，表示区间宽度，不带正负号。非退化公差区间的公差为正值。
对象 上偏差 下偏差 极限尺寸 公差
孔 (ES) (EI) (D_{max}=D+ES), (D_{min}=D+EI) (T_D=ES-EI)
轴 (es) (ei) (d_{max}=d+es), (d_{min}=d+ei) (T_d=es-ei)

尺寸标注必须满足上偏差不小于下偏差，否则会导致“最大极限尺寸小于最小极限尺寸”的矛盾。

公差带代号

公差带代号由基本偏差字母和标准公差等级数字组成，如 H8 或 f7：

  • 大写字母表示孔，小写字母表示轴。
  • 基本偏差确定公差带相对零线的位置；IT 等级确定宽度。
  • 基准孔 H 的 (EI=0)；基准轴 h 的 (es=0)。
  • IT 数字越小通常表示公差越小、制造精度越高；但实际公差值还与基本尺寸分段有关，应按适用标准查表。

同名孔、轴公差带的换算不能无条件地当作关于零线的镜像。某些字母和等级组合需使用标准规定的特殊换算规则，应依题目指定版本查表，不用“同名即取反”代替标准。

配合的计算与判定

统一使用“孔减轴”可减少符号混乱：

[
X_{max}=D_{max}-d_{min}=ES-ei
]

[
X_{min}=D_{min}-d_{max}=EI-es
]

  • (X_{min}>0)：所有组合均有间隙，为间隙配合。
  • (X_{max}<0)：所有组合均有过盈，为过盈配合。此时 (-X_{max}=d_{min}-D_{max}) 是最小过盈。
  • (X_{min}\le 0\le X_{max})：可能间隙也可能过盈，为过渡配合；端点为零时存在零间隙边界。

若单独使用正值的过盈量，则：

[
Y_{max}=d_{max}-D_{min}=es-EI=-X_{min}
]

[
Y_{min}=d_{min}-D_{max}=ei-ES=-X_{max}
]

配合公差是配合结果的变动范围：

[
T_f=T_D+T_d=X_{max}-X_{min}=Y_{max}-Y_{min}
]

最后一个等式只适用于把 (Y_{max}) 和 (Y_{min}) 都定义为正的过盈量时。不应在同一计算中混用“正过盈”和“负间隙”两套符号。

基准制与工程选择

  • 基孔制：固定 H 孔，用不同轴公差带获得所需配合。孔的定尺工具和量具调整成本较高时，通常更经济。
  • 基轴制：固定 h 轴，用不同孔公差带获得所需配合，适用于标准轴、一轴多孔等具体结构约束。

设计时要分别选择基准制、公差等级和配合种类。总原则是先确定功能边界，再选能满足它的较经济制造精度，而不是一律选最小公差。

优先数与标准化尺寸

R5、R10、R20 等优先数系列是把一个十倍区间按近似等比分割，用于减少规格种类并保持尺寸系列的合理比例。R 后数字越大，同一十倍区间内的项越多。派生系列 Rr/p表示从 Rr 中每隔 (p) 个指数取一项；起点必须由题目或标准指定。例如 R10/3 的精确比值为 (10^{3/10}\approx1.995)，因此使用圆整值时可见 1, 2, 4, 8, 16, 31.5, ...。

一个十进段内常用的圆整值为：

  • R5：1.00, 1.60, 2.50, 4.00, 6.30, 10.0；
  • R10：1.00, 1.25, 1.60, 2.00, 2.50, 3.15, 4.00, 5.00, 6.30, 8.00, 10.0。

跨越十进段时按 10 的整数次幂缩放。求有限区间内的派生系列时，应先确定属于该派生序列的起始相位，再筛选落入区间的项；“取区间内第一个母系列数后每三项取一项”只有当该数恰好属于指定相位时才成立。

计算检查顺序

  1. 统一单位，尤其注意 (1\,\mathrm{mm}=1000\,\mu\mathrm{m})。
  2. 从代号分离“孔/轴、基本偏差、IT 等级”。
  3. 查得偏差后先验证“上偏差 ≥ 下偏差”和公差宽度。
  4. 计算极限尺寸，再用孔减轴计算 (X_{max}) 与 (X_{min})。
  5. 用 (T_f=T_D+T_d) 与 (X_{max}-X_{min}) 交叉校验。
  6. 画公差带图时先画零线，再按上、下偏差画孔轴两个区间；不凭字母印象判断配合性质。
